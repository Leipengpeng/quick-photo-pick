# Quick Photo Pick 实验结果

## 连拍分组

将 HDR+ 子集的 250 张 DNG 及 28 个已知连拍组作为标注对照。完整分组要求预测组和标注组成员完全一致。错并以预测为同组的图对为分母，错拆以标注为同组的图对为分母。 [HDR+ 数据说明](https://storage.googleapis.com/hdrplusdata/README.html)

| 方法 | 完整分组 | 错并图对 | 错拆图对 |
| --- | ---: | ---: | ---: |
| Facet 分组对照 | 25/28 | 60/1,052 | 27/1,019 |
| Quick Photo Pick | **28/28** | **0/1,019** | **0/1,019** |

## 人像与清晰度

EyeBlink8 测试取 4 人、8 段视频中的 360 张单人抽帧，提供已知的三张一组。完全闭眼正例指至少一眼完全闭合。360 张都检测到人脸。 [EyeBlink8 作者研究页](https://www.blinkingmatters.com/research#datasets)

| 指标 | Facet 对照 | Quick Photo Pick |
| --- | ---: | ---: |
| 完全闭眼检出 | 64/120（53.33%） | **119/120（99.17%）** |
| 睁眼误报 | 1/240（0.42%） | 2/240（0.83%） |
| 推荐首位为睁眼样本 | 105/120 | **119/120** |
| 实拍清晰图排在抖糊图前 | 61/71（85.92%） | **65/71（91.55%）** |

Facet 的闭眼对照使用固定阈值，推荐首位与清晰度行使用 Facet 技术排序对照。71 对清晰与相机抖糊图来自 GimbalBlur 子集，专项拉普拉斯指标在同一组为 67/71。另在魔搭人像合成降质测试的 2,000 对中，综合评分把 1,945 张参考图排在降质图之前。 [GimbalBlur 项目](https://akionu.github.io/GimbalBlur/) · [魔搭数据卡](https://www.modelscope.cn/datasets/modelscope/image-portrait-enhancement-dataset/)

## 场景聚类

- 跨日期拍摄的同一处彩窗场景，两组代表图在 142 个匹配中有 108 个几何内点，对齐后双向重叠约 90.0% 和 86.5%。两组各自保留排名，在报告中聚合为同一场景。
- 四种题材各取一张原片，每轮独立裁两次，保留约 80% 面积并加入轻微旋转和透视扰动。24/24 轮正确分为四类，96 个同源图对均聚合，576 个跨源图对均分开。
- 在同场景实拍配对对照里，恢复 61/70 个同视图图对，2,415 个跨场景图对未出现错并。同视图标签以场景和拍摄设备划分。

## 运行时间

| 实测任务 | 结果 | 单次本地计时 |
| --- | --- | ---: |
| 混合格式实机演示 | 50 张，其中 11 张 DNG 直接分析。8 个连拍组、7 个场景、9 张推荐 | 仅连拍分组 5.57 秒，处理、报告生成及副本核验 21.08 秒 |
| 250 张已标注 DNG | 恢复 28 个连拍组，聚合成 27 个场景 | 仅连拍分组 42.28 秒，本地流水线 81.73 秒 |
| 已分组单人专项 | 360 张、640×480、四进程本地测试 | 7.69 秒 |

这些记录来自不同任务。分组耗时、分析与导出用时、已知分组人像专项各自独立计时。综合排序以已标注的睁眼、清晰或高质量参考为目标。场景随机裁切实验在有限的原片上重复生成变体。仓库保留量化结论，实验原图由官方数据页提供。

## 复跑入口

安装完成后，将有标注的样本整理成数据目录。`hdrplus_manifest.json` 按样本提供相对于数据目录的 `path`、真实连拍 `group` 和 `exif`。人像专项读取 `eyeblink8_manifest.json` 的 `path`、`group` 和 `label`，其中完全闭眼标签为 `fully_closed_in_at_least_one_eye`。使用相同的样本及分组口径时，可复核上面的计数。

```shell
python burst_engine/benchmark.py groups --data benchmark_data --out outputs/bench-groups
python burst_engine/evaluate_workflow.py --dataset eyeblink8 --data benchmark_data --out outputs/bench-eyes --workers 4 --iqa-report
```
